# Job Board

A simple job board built with Next.js, Supabase, TailwindCSS, GitHub Actions, and deployed on Vercel.

## Features
- 🔍 Browse jobs
- 📝 Post jobs
- 👤 User dashboard
- ❤️ Save/bookmark jobs (future feature)

## Tech Stack
- Next.js
- Supabase
- TailwindCSS
- GitHub Actions
- Vercel

## CI/CD
- Auto build & deploy on push to `main`

## Deployment
- Hosted on Vercel
